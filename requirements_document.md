# Password Reset Requirements

As a registered customer, I want to reset my password using a time-limited email link.
The link must expire after 15 minutes and must not work after it has been used once.
The system should show a success message immediately after the request is submitted.
The email should include a secure reset token.
The password rules are still being finalized and may change.
The reset link should expire after 10 minutes and also remain valid for 15 minutes.
If the account is temporarily locked, the reset link should still work according to the business team.
